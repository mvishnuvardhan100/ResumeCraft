# ResumeCraft

A frontend-only resume builder built with React, Vite, Tailwind CSS, and React Router.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```

## Features

- Three resume templates: Minimal, Professional, and Creative
- Step-by-step resume editor
- Live preview
- Optional profile photo upload (stored locally in browser state)
- Multiple education, experience, and project entries
- Browser localStorage autosave
- PDF export

All resume data stays in the user's browser. There is no backend.
